* El error de la industria
Las empresas, como tienen distintas formas de hacer sus equipos, tenían cada una, distintos instruccion set para decirle al hardware que hacer, por lo tanto, para cada empresa se tenia que programar de distinta forma.

Como programar así es una locura, se crearon los lenguajes de alto nivel, donde el programador puede escribir en un lenguaje legible y un compilador que traduce esas instrucciones en cada maquina.

* Que es compilar?
Básicamente, se traduce el código fuente, escrito por el programador, hacia un programa objeto, el cual básicamente es un lenguaje no de 1's y 0's sino uno mas parecido al assembler

por ejemplo

int area = base * altura

compilando..

 #+begin_src
    LOAD R1, base
    MUL R1, altura
    DIV R1, 2
    STORE area, R1
 #+end_src

Entonces, así el ensamblador puede traducir estas instrucciones en lenguaje puramente de maquina
* Que NO es compilar?
Básicamente no adivina el significado, no corrige el código, no lo ejecuta tampoco y no cambia la semántica valida del programa

* Fases de la compilación
Compilar se divide en 8 bloques que a groso modo son:
- Código fuente
- Preprocesamiento
- Análisis léxico
- Análisis sintáctico
- Análisis semántico
- Generación de código intermedio
- Optimización de código
- Generación de código objeto

Sin embargo, como hay partes que prácticamente analizan y otras que solo generan, se dividió a la compilación en dos etapas
** Análisis o front - end
En esta fase se comprende el programa lexicamente, que palabras o símbolos hay, sintacticamente, como se organizan, y semanticamente, tiene sentido.
** Síntesis o back-end
Donde se cambia todo este código analizado en código para maquina haciendo una representación intermedia, optimizandolo, y dándole las instrucciones a la maquina
* Componentes
Ademas de estas fases hay dos cosas que acompañan la compilación.
** Tabla de símbolos
Se ponen nombres, tipos, alcance y otras propiedades del código
** Manejador de errores
Básicamente detecta, reporta y apoya la recuperación ante errores encontrados.
