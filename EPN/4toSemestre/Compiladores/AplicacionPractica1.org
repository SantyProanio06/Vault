El ejercicio nos pide ingresar valores enteros hacia un vector, siempre seran ingresados en positivo independientemente de lo que ingrese.Calcular el promedio de los valores ingresados e imprimir el resultado.
Estos ejercicios son demasiado iguales a von neuman, donde se lee el codigo de operacion y se operan las localidades de memoria en base a lo que este alli.

Como vimos en  [[id:cc391668-4c4c-4ed2-a9ce-3ddc4969e118][Las instrucciones]], para este ejercicio tenemos un set de instrucciones

[[attachment:20261011-150456_screenshot.png]]
