* Ejercicio
Teniendo en cuenta como funcionan las instrucciones, haremos el siguiente ejercicio con dos direcciones. *Diseñe una solución con el siguiente set de instrucciones*:
Leer tres números A, B y C, realizar R = (A + B) x C, imprimir el resultado R. Crear las instrucciones en lenguaje ensamblador usando solo READ, MOV, ADD, MUL, PRINT.
** Crear el código
Para hacer el ejercicio lo primero que hay que hacer es crear el código que permite resolver el problema, teniendo en cuenta el set de instrucciones,

#+begin_src
int A, B, C;
int R = 0;
Leer A;
Leer B;
Leer C;
R = (A + B) x C;
print(R);
#+end_src
** Instrucciones
Ahora si podemos hacer las instrucciones

#+begin_src
READ A
READ B
READ C
MOV R, 0
ADD R, A
ADD R, B
MUL R, C
PRINT R
#+end_src
** Comprobamos con una traza para ver si es que existen errores
A = 2, B = 3, C = 4
R = 0
R = R + A
# R = 0 + 2
R = R + B
# R = 2 + 3
R = R * C
# R = 5 * 4
Print(R)
