Algoritmo prefixAverges2(X, n)
input arreglo de n enteros
output arreglo A de prefijos promedios de X

1 A = arreglo de n enteros
2 s = 0
3 for i = 0 to n - 1 do
4 s = s + X[i]
5 A[i] = s / (i + 1)
6 return A
