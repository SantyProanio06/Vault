* Qué es una base de datos?
Es básicamente un conjunto de datos homogéneos, o sea del mismo tipo, amancebados y organizados de una forma especia para ser usados y procesados por una computadora de manera rápida y sencilla. Pero
** Qué es un dato?
Un dato es la representación de un hecho aislado que por si solo no significa nada, por ejemplo un número o una cadena de caracteres. Por ejemplo, 202420587, o Santiago
** Qué es información?
Es el procesamiento y la contextualización de dichos datos, es aquí donde adquieren un significado, por ejemplo estando en el SAEw el código 202420587 es el código único del estudiante Santiago.
* DBMS
De las siglas data base managment system (sistema de gestión de bases de datos), nos ayuda a gestionar toda la información, mantener y realizar consultas sobre una base de datos. Esta caracterizado por:
- Globalización de la información: permite centralizar la información de una organización.
- Elimina:
  * Redundancia
  * Inconsistencia
  * Problemas de seguridad
  * Problemas de acceso concurrente
  * Problemas de integridad (por medio de restricciones a los datos)
